# خريطة الموقع

## صفحات الموقع

- `/` — الصفحة الرئيسية، وتعرض الوظائف الحالية التي لها واجهة معالجة.
- `/convert/` — مساحة تحويل الصور وتحريرها.
- `/image-converter/` — صفحة تجميعية لأدوات الصور مع رابط إلى المساحة الحالية.
- `/pdf-tools/` — صفحة تجميعية توضّح أن أدوات PDF لم تُفعّل بعد.
- `/guide/` — دليل الاستخدام.
- `/privacy/` — سياسة الخصوصية.
- `/<slug>/` — صفحات تعريف مستقلة لمهام التحويل الواردة في `src/data/tool-catalog.ts`.
- `/sitemap.xml` — خريطة XML تشمل المسارات المنشورة ومسار GitHub Pages.

## حالة التشغيل الحالية

- صفحات المهام أعلاه صفحات تعريفية فقط؛ لا تعرض رفع ملفات أو أزرار معالجة.
- إزالة الخلفية غير مدرجة في دليل الأدوات العام حتى اعتماد اختبار فعلي للموديل والأداء والجودة.
- لا تظهر أدوات PDF في دليل الأدوات حتى تتوفر معالجة محلية مجرّبة.
- لم تُضف مكتبات ثقيلة في هذه المرحلة؛ تحميل المكتبات يخص مرحلة تنفيذ كل أداة.
- لا توجد واجهة Backend، وتظل معالجة الصور الحالية داخل المتصفح.

## قواعد النشر وSEO

- صفحات Astro ثابتة وتستخدم المسارات الإنجليزية القصيرة.
- الروابط الداخلية وcanonical وsitemap تستخدم `BASE_URL` بما يشمل `/file-conversion-platform/` عند النشر على GitHub Pages.
- عنوان ووصف كل مهمة يختلفان وفق نوع التحويل وخصائص صيغته.
- لا يُعلن عن أداة معالجة على أنها متاحة قبل اختبارها؛ صفحات المهام غير المفعّلة تنبه المستخدم صراحةً إلى عدم رفع الملفات.
