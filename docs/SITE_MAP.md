# خريطة الموقع ودليل الأدوات

هذه الوثيقة مرجع تنظيمي للقالب. حالة «قريبًا» تعني أن الصفحة التعريفية موجودة ضمن الخريطة فقط، ولا تعني أن أداة المعالجة نُفذت أو اختُبرت.

## القالب والصفحات المشتركة

- / — الصفحة الرئيسية ودليل الأدوات، مع البحث والتصنيفات.
- /convert/ — مساحة العمل الحالية لتحويل الصور وتعديلها.
- /guide/ — دليل الاستخدام.
- /privacy/ — سياسة الخصوصية.
- /tools/<slug>/ — صفحة ثابتة للأداة المخططة؛ تعرض حالة «قريبًا» حتى تنفيذ الأداة واختبارها.
- رأس موحد، تنقل رئيسي، تذييل، خطوط عربية، اتجاه RTL، حالات تركيز لوحة المفاتيح، وتصميم متجاوب.

## الأدوات المستقبلية المخططة

تُدار الأسماء والروابط والحالة في src/data/tool-catalog.ts. لكل أداة مخططة مسار ثابت على نمط /tools/<slug>/؛ تعرض الصفحة حالة «قريبًا» ولا تعرض نموذج رفع أو زر معالجة غير فعّال.

### تحرير الصور
- /tools/image-metadata/ — إزالة بيانات الصورة الوصفية.
- /tools/image-watermark/ — إضافة علامة مائية.
- /tools/image-compare/ — مقارنة قبل وبعد.

### PDF
- /tools/image-to-pdf/ — تحويل الصور إلى PDF.
- /tools/pdf-to-images/ — تحويل PDF إلى صور.
- /tools/pdf-merge/ — دمج ملفات PDF.
- /tools/pdf-split/ — تقسيم PDF.
- /tools/pdf-compress/ — ضغط PDF.
- /tools/pdf-rotate/ — تدوير صفحات PDF.

### المستندات
- /tools/word-to-pdf/ — تحويل Word إلى PDF.
- /tools/pdf-to-word/ — تحويل PDF إلى Word.
- /tools/excel-to-pdf/ — تحويل Excel إلى PDF.
- /tools/powerpoint-to-pdf/ — تحويل PowerPoint إلى PDF.

### الصوت
- /tools/audio-convert/ — تحويل صيغ الصوت.
- /tools/audio-compress/ — ضغط الصوت.
- /tools/extract-audio/ — استخراج الصوت من الفيديو.

### الفيديو
- /tools/video-convert/ — تحويل صيغ الفيديو.
- /tools/video-compress/ — ضغط الفيديو.
- /tools/video-trim/ — قص الفيديو.

### الملفات والأرشيف
- /tools/zip-create/ — ضغط الملفات إلى ZIP.
- /tools/zip-extract/ — فك ضغط ZIP.

## ضوابط التنفيذ مستقبلًا

1. لا يُعلن دعم تنسيق إلا بعد تحويل فعلي وفحص MIME وتوقيع الملف الناتج واختبار التنزيل.
2. لا تُعتبر صفحة «قريبًا» أداة جاهزة.
3. تُفضّل المعالجة المحلية، ولا يُرفع محتوى الملفات إلى خادم دون قرار منفصل ومبرر واضح.
4. تستخدم كل أداة القالب المشترك، مع حالات رفع ومعاينة وخيارات ونتيجة موحدة عندما يحين تنفيذها.
5. تُختبر الروابط، وRTL، ولوحة المفاتيح، والهاتف، والأخطاء، والخصوصية ضمن معايير قبول الأداة.
6. لا دمج إلى main دون موافقة مستقلة.

## معايير قبول القالب

- تصنيف وبحث يعملان على الأدوات الحالية والمخططة.
- لكل أداة مخططة اسم واضح، وتصنيف، ووصف، ورابط ثابت، وعلامة «قريبًا».
- لا توجد أزرار تحويل أو رفع وهمية في صفحات الأدوات المستقبلية.
- رأس وتذييل موحدان، وعرض متجاوب، وخط عربي واضح.
- نجاح npm test وnpm run check والبناء، ومراجعة نتائج اختبارات المتصفح دون إخفاء أي إخفاق.
