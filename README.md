# منصة تحويل الملفات — نموذج أولي عربي

منصة عربية أولًا لبناء أدوات تحويل وتحرير ملفات تعمل فعليًا، مع أولوية للمعالجة داخل المتصفح وحماية ملفات المستخدم. الموقع ما زال نموذجًا أوليًا وليس منتجًا نهائيًا.

## الحالة الحالية

- فرع التطوير: `phase-1-prototype`؛ طلب الدمج رقم 1 ما زال مسودة ولم يُدمج إلى `main`.
- آخر نسخة تحقق مكتمل حتى الآن: `426fbd9eea700b1a3d98b3b23556c7f0cd78e563`.
- نجحت الاختبارات المنطقية وفحص Astro/TypeScript والبناء واختبارات Chromium: **35/35**. [سجل الجودة](https://github.com/ashraf18275/file-conversion-platform/actions/runs/39705893663).
- نُشرت معاينة الفرع بنجاح. [سجل النشر](https://github.com/ashraf18275/file-conversion-platform/actions/runs/39705888095).
- اجتاز آخر commit فحص الجودة واختبارات Chromium (**35/35**)، بما فيها التحقق من مسارات الأدوات المخططة وعرض دليل الأدوات على شاشة هاتف 390 بكسل. نُشرت معاينته بنجاح. تبقى تجربة إزالة الخلفية الحقيقية على هاتف والتحققات اليدوية ضمن الأعمال المتبقية.

## ما يتضمنه النموذج الأولي

- تحويل الصور محليًا إلى PNG وJPEG وWebP وBMP.
- تغيير الأبعاد، والاقتصاص الرقمي والبصري، والتدوير والقلب.
- ضغط JPEG/WebP مع تحكم بالجودة ومحاولة استهداف حجم تقريبي.
- تحسين أساسي للسطوع والتباين وتشبع الألوان.
- قائمة متعددة الملفات وترتيبها وإزالتها وتنزيل النتائج.
- إزالة خلفية تجريبية محلية؛ اختبارات الواجهة تستخدم نتيجة محاكاة، ولم تُعتمد بعد جودة النموذج الحقيقي أو سرعته على أجهزة Android.
- دليل أدوات فيه 21 أداة مستقبلية وصفحات تعريفية «قريبًا». وجود الصفحة لا يعني أن الوظيفة نُفّذت.

## الصفحات والقالب

- `/` — الصفحة الرئيسية ودليل الأدوات، مع البحث والتصنيفات.
- `/convert/` — محرر الصور الحالي.
- `/guide/` — دليل الاستخدام.
- `/privacy/` — سياسة الخصوصية.
- `/tools/<slug>/` — صفحة تعريفية للأداة المستقبلية، دون رفع أو معالجة وهمية.

روابط التوثيق:

- دليل التصميم المشترك: `docs/DESIGN_SYSTEM.md`
- حالة المشروع: `PROJECT_STATUS.md`

## التشغيل المحلي

يتطلب Node.js 22 أو إصدارًا متوافقًا حديثًا:

```sh
npm install
npm test
npm run check
npm run build
npm run dev
```

لاختبارات Chromium:

```sh
npx playwright install --with-deps chromium
npm run test:e2e
```

## الخصوصية والقيود

- التحويل الأساسي يجري في المتصفح، ولا توجد قاعدة بيانات أو نقطة رفع لملفات المستخدم في النموذج الأولي.
- قد يتصل المتصفح بمزوّد خارجي لتنزيل مكتبة ونموذج إزالة الخلفية عند أول استخدام؛ هذا لا يعني رفع الصورة، لكن يجب مراجعة الشبكة الفعلية قبل الإطلاق.
- اختبارات CI لا تستبدل اختبار الهاتف الحقيقي، ولا تثبت جودة إزالة الخلفية على كل الصور.
- لا دمج إلى `main` ولا خدمات مدفوعة أو نشر نهائي دون موافقة مستقلة.
