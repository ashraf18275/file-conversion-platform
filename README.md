# منصة تحويل الملفات — محوّل الصور

منصة عربية أولًا لتحويل الملفات، مع أولوية للمعالجة المحلية والخصوصية. المرحلة الأولى تبني نموذجًا أوليًا لأداة تحويل الصور إلى PNG وJPEG وWebP.

## الحالة
- صفحات رئيسية وتحويل ودليل وخصوصية على فرع `phase-1-prototype`.
- اختبارات منطقية بسيطة باستخدام Node.js.
- البناء وسلوك المتصفح والخصوصية لم تُعتمد بعد.

## التشغيل
يتطلب Node.js 22 أو إصدارًا متوافقًا حديثًا:
```sh
npm install
npm test
npm run build
npm run dev
```

## الصفحات
- `/` الصفحة الرئيسية.
- `/convert/` تحويل الصور محليًا.
- `/guide/` دليل الاستخدام.
- `/privacy/` شرح مبدئي للخصوصية.

راجع `PROJECT_MASTER.md` و`PROJECT_STATUS.md` و`TESTING.md` قبل أي توسع. لا توجد خدمة رفع ملفات أو قاعدة بيانات في النموذج الأولي.
