# منصة تحويل الملفات — محوّل الصور

منصة عربية أولًا لتحويل الملفات، مع أولوية للمعالجة المحلية والخصوصية. المرحلة الأولى تبني نموذجًا أوليًا لأداة تحويل الصور إلى PNG وJPEG وWebP.

## الحالة
- صفحات عربية رئيسية وتحويل ودليل وخصوصية على فرع `phase-1-prototype`.
- اختبارات منطقية عبر Node.js واختبارات متصفح Chromium.
- الاختبارات الآلية والبناء ناجحة؛ راجع `PROJECT_STATUS.md` لسجل آخر تشغيل.
- الموقع لم يُنشر، والفرع لم يُدمج في `main`.

## التشغيل المحلي
يتطلب Node.js 22 أو إصدارًا متوافقًا حديثًا:
```sh
npm install
npm test
npm run check
npm run build
npm run dev
```

## اختبارات المتصفح
لتثبيت Chromium وتشغيل اختبارات التحويل والخصوصية:
```sh
npx playwright install --with-deps chromium
npm run test:e2e
```

## الصفحات
- `/` الصفحة الرئيسية.
- `/convert/` تحويل الصور محليًا.
- `/guide/` دليل الاستخدام.
- `/privacy/` شرح مبدئي للخصوصية.

## النطاق والخصوصية
لا توجد خدمة رفع ملفات أو قاعدة بيانات في النموذج الأولي. يجرى التحويل عبر واجهات المتصفح. اختبارات Chromium تتحقق من التحويلات الأساسية وغياب طلبات HTTP/HTTPS بعد اختيار الملف، لكنها لا تغني عن اختبار يدوي على أجهزة ومتصفحات حقيقية.

راجع `PROJECT_MASTER.md` و`PROJECT_STATUS.md` و`TESTING.md` قبل أي توسع.
