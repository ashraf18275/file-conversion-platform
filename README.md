# منصة تحويل الملفات — محوّل الصور

منصة عربية أولًا لتحويل الملفات، مع أولوية للمعالجة المحلية والخصوصية. المرحلة الأولى تبني نموذجًا أوليًا لأداة تحويل الصور إلى PNG وJPEG وWebP.

## الحالة الحالية
- صفحات عربية رئيسية وتحويل ودليل وخصوصية على فرع `phase-1-prototype`.
- اختبارات Node.js الأربعة واختبارات متصفح Chromium الثمانية عشر ناجحة في آخر تشغيل موثق.
- فحص Astro والبناء ناجحان.
- نُشرت معاينة GitHub Pages: https://ashraf18275.github.io/file-conversion-platform/
- الفرع لم يُدمج في `main`. المعاينة لا تعني أن المنتج جاهز للإطلاق؛ يلزم اختبار يدوي على أجهزة حقيقية.

راجع `PROJECT_STATUS.md` و`TESTING.md` لنتائج التشغيل وروابطها.

## التشغيل المحلي
يتطلب Node.js 22 أو إصدارًا متوافقًا حديثًا:
```sh
npm install
npm test
npm run check
npm run build
npm run dev
```

## اختبارات المتصفح
لتثبيت Chromium وتشغيل اختبارات التحويل والخصوصية:
```sh
npx playwright install --with-deps chromium
npm run test:e2e
```

## الصفحات
- `/` الصفحة الرئيسية.
- `/convert/` تحويل الصور محليًا.
- `/guide/` دليل الاستخدام.
- `/privacy/` شرح مبدئي للخصوصية.

## النطاق والخصوصية
لا توجد خدمة رفع ملفات أو قاعدة بيانات في النموذج الأولي. يجرى التحويل عبر واجهات المتصفح. اختبارات Chromium تتحقق من التحويلات الأساسية وغياب طلبات HTTP/HTTPS الناتجة عن التحويل، لكنها لا تغني عن اختبار يدوي على أجهزة ومتصفحات حقيقية.

راجع `PROJECT_MASTER.md` و`PROJECT_STATUS.md` و`TESTING.md` قبل أي توسع.
